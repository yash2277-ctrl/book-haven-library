========================================

MongoDB Atlas signup page is opening in your browser...

STEP 1: Sign Up (1 minute)
   → Use Google/GitHub for fastest signup
   → Or enter email and create account

STEP 2: Create FREE Cluster (2 minutes)
   → Choose "M0 FREE" tier
   → Select AWS provider
   → Pick closest region
   → Click "Create Deployment"

STEP 3: Security (1 minute)
   → Username: bookhavenuser
   → Password: Click "Autogenerate" (SAVE THIS!)
   → Network: "Allow Access from Anywhere"

STEP 4: Get Connection String (30 seconds)
   → Click "Connect" button
   → Choose "Drivers"
   → Copy the connection string
   → It looks like:
     mongodb+srv://bookhavenuser:<password>@cluster.mongodb.net/

STEP 5: Update Backend (30 seconds)
   → Open: backend\.env
   → Change MONGODB_URI to:
     MONGODB_URI=mongodb+srv://bookhavenuser:YOUR_PASSWORD@cluster0.xxxxx.mongodb.net/book_haven
   → Save file

STEP 6: Seed Database (30 seconds)
   Run in PowerShell:
   
   cd "c:\Users\sahu4\OneDrive\Pictures\Screenshots\libary\book-haven-display-main\backend"
   npm run seed

STEP 7: Start Backend (10 seconds)
   In the same terminal:
   
   npm run dev

STEP 8: Start Frontend (10 seconds)
   Open NEW PowerShell and run:
   
   cd "c:\Users\sahu4\OneDrive\Pictures\Screenshots\libary\book-haven-display-main"
   npm run dev

STEP 9: Open Browser
   → Go to: http://localhost:8080
   → Login with: alex@example.com / password123
