# Book Haven — Library Management System

A modern library management web application with a beautiful UI, animated landing page, catalog browsing, and book borrowing system.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** — fast dev server & build
- **Tailwind CSS** + **shadcn/ui** — styling & components
- **Framer Motion** — animations
- **React Router v6** — routing
- **React Query** — data fetching
- **date-fns** — date utilities

## Getting Started

```sh
# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at **http://localhost:8080**.

## Features

- Animated landing page with parallax, typewriter text, and floating elements
- One-click demo account login
- Browse & search a catalog of 36+ books
- Borrow, return, and renew books
- Personal dashboard with borrowing stats
- Fully responsive design
